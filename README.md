# Simple Calculator

A lightweight calculator project built with Python.

## Overview

This repository contains a simple calculator created to practise programming fundamentals and basic arithmetic operations.

## Features

- Simple, beginner-friendly calculator workflow
- Basic arithmetic operations, depending on the implemented functions
- Small project suitable for practising Python fundamentals

## Getting Started

1. Install Python 3.
2. Clone this repository:
   ```bash
   git clone https://github.com/Dhanush-0303/Simple-Calculator.git
   cd Simple-Calculator
   ```
3. Run the Python script included in the repository:
   ```bash
   python <script-name>.py
   ```

Replace `<script-name>.py` with the actual Python file name in the repository.
